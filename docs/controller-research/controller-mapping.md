## Controller Mapping

### MinVerse (better controls, less inputs)
> Note: The MinVerse only has two buttons. This could complicate controls, especially since the buttons are located directly on the stylus which can be easily be misclicked by a pinch.

| Input | Action |
|---|---|
| Button 1 | Toggle between base and upper joints  |
| Button 2 | Return to 0 pose or stop/hold current position* |

> \* The most important buttons need to be used here... this means choosing between either or. Or, we could have a separate control pad for more inputs/controls.
