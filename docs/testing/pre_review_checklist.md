# Pre-Review Checklist
Below is a checklist for team members to review before submitting a pull request. Before asking Yassin to review, ensure the following:

- [ ] Branch is current with the main branch (rebase or merge main into your branch)
- [ ] CI is green (refer to smoke testing document [here](integration_smoke_testing.md) and any other relevant testing for your branch)
- [ ] Ensure that the PR description is substantive; including:
  - [ ] Purpose of the branch
  - [ ] Changes/fixes/features included depending on purpose of the branch
  - [ ] Include commands used for testing, demo, and other relevant information for validation
  - [ ] List known limitations, bugs, or issues encountered which are not resolved in this branch
  - [ ] Include screenshots, logs, or demo videos where applicable to demonstrate the changes made in this branch
